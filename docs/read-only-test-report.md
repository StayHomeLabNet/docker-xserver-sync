# XServer読み取り専用接続試験

実施日: 2026-11-01

## 試験範囲

- 保存済みプロジェクト設定の読み込み
- SSH公開鍵認証
- SHA-256ホスト鍵フィンガープリント照合
- ポート10022への接続
- SFTPによるテスト用リモートディレクトリの一覧取得
- ローカルとリモートの差分計画作成

## 結果

| 項目 | 結果 |
|---|---|
| SSH接続 | 成功 |
| ホスト鍵照合 | 成功 |
| リモートパス走査 | 成功 |
| ローカル走査 | 成功 |
| ADD | 0 |
| UPDATE | 0 |
| SAME | 0 |
| REMOTE_ONLY | 0 |
| ブロッキングエラー | 0 |
| リモート書き込み | なし |

ローカルのテストフォルダとXServerのテストフォルダがともに空だったため、接続と空ディレクトリ走査の確認となった。

## 補足

- リモートへのファイル・ディレクトリ・ロック・一時ファイル作成は行っていない。
- 次回はローカルテストフォルダに無害なサンプルファイルを置き、`ADD`として検出されることを確認する。
- 秘密鍵ファイルのアクセス権は所有者のみ読み書き可能な`600`を推奨する。

## 追加試験

### ADD検出

ローカルテストフォルダへ無害なMarkdownファイルを1個置いて再実行した。

- `ADD`: 1
- `UPDATE`: 0
- `REMOTE_ONLY`: 0
- ブロッキングエラー: 0
- リモート書き込み: なし

### ホスト鍵不一致

保存済みフィンガープリントの末尾を意図的に変更して接続した。

- 結果: 接続拒否
- 実際のフィンガープリントとの不一致を検出
- SFTP走査開始前に停止
- リモート書き込み: なし

### 秘密鍵権限

ローカル秘密鍵のアクセス権を所有者のみ読み書き可能な`600`へ変更した。

## リモートバックアップ実環境試験

公開ディレクトリとは分離したXServerホーム配下の専用領域で実施した。

```text
$HOME/.dxsync/test-fixtures/backup-engine/
$HOME/.dxsync/backups/{project_id}/{plan_id}/
```

結果:

- 専用テストファイル作成: 成功
- ジョブ別バックアップディレクトリ作成: 成功
- 1ファイル、43バイトのコピー: 成功
- コピー前後のSHA-256一致: 成功
- バックアップマニフェスト作成: 成功
- マニフェスト再読込検証: 成功
- 公開テストディレクトリへの書き込み: なし

バックアップ後に公開テストディレクトリを再走査し、引き続きローカルサンプルファイルが`ADD 1`、リモート側が空であることを確認した。

テスト用フィクスチャとバックアップは復元試験で使用するため、`.dxsync`配下に保持している。
