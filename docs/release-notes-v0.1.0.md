# Docker XServer Sync v0.1.0

データベースを使用しないWordPress、Laravel、独自PHPサイトのファイルを、Dockerのbind mount元からXServerへ安全に同期する初回リリースです。

## 主な機能

- Windows・macOS対応のPySide6デスクトップGUI
- SSHホスト鍵フィンガープリントの厳密照合
- 読み取り専用ドライランと承認前再検証
- SHA-256検証付き一時転送と安全な公開切り替え
- UPDATE・承認済み削除対象の事前バックアップ
- 途中失敗時のロールバックと履歴からの復元
- 本番書き込みディレクトリの保護
- 同期後HTTPSヘルスチェック
- REMOTE_ONLY削除候補の個別選択と二重承認

## 検証状況

- 自動テス68件成功
- Windows x64実機でプロジェクト保存、秘密鍵選択、ドライラン、ADD・UPDATE、保護先除外、HTTPSヘルスチェックを確認済み
- Windows x64実機で承認付き削除、更新・削除ファイルの復元、転送中断時の回復性を確認済み
- GitHub Windowsランナーでビルド、起動、インストール、インストール後起動、アンインストールを検証

## 注意点

- MySQLのバックアップ・同期・復元は未実装です。
- Windows版・macOS版とも現時点ではコード署名前です。OSの警告が表示される場合があります。
