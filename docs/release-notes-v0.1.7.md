# v0.1.7

## APIキー不要のWordPress初回セットアップ

- MySQLの準備方法に「作成済みDBを使用（APIキー不要）」を追加し、既定の選択肢に変更
- XServerのサーバーパネルで作成したDB名、MySQLユーザー名、ホスト、パスワードを直接入力可能
- XServer APIを利用できる環境では、従来どおりAPIによるDB・ユーザーの新規作成も選択可能

## 安全確認

- 作成済みDBへの接続をSSH経由で事前確認
- DBのテーブル数を確認し、空でない場合はSQL転送・インポート・WordPressファイル配置を開始せず停止
- DBやMySQLユーザーを自動削除・初期化しない
- DBパスワードは永続保存せず、SSH先の一時設定ファイルを権限`0600`で作成して処理後に削除
- 失敗時にSQLインポート開始前後を区別して案内

## UIとドキュメント

- API方式と作成済みDB方式で入力欄を自動切り替え
- 最終確認画面に、作成または使用するDBとMySQLユーザーを表示
- 初回設定ガイドとWordPress初回セットアップ仕様を更新

## 検証

- 自動テスト108件に成功
- macOS Apple Silicon版の起動スモークテストとZIP整合性を確認
