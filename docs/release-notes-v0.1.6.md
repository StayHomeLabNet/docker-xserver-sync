# v0.1.6

## 自動実行の確認設定

- プロジェクト別の「自動実行設定」に、最終確認で対象ドメインの再入力を要求するか選べる項目を追加
- 安全性を維持するため初期値は再入力あり
- 再入力を省略しても、転送先・変更件数、自動処理内容の確認チェックと明示承認は必須

## WordPress初回セットアップ

- ローカルDockerのWordPressを空のXServerへ配置するウィザードを追加
- XServer APIによるMySQLデータベース・ユーザー作成、SQLインポート、`wp-config.php`生成、URL置換、HTTPS確認に対応
- WordPressコアを必須とし、`wp-content/`のアップロード対象を選択できる画面を追加
- メイン画面の専用パネルと「プロジェクト」メニューからウィザードを開始可能

## 同期対象とUI

- `.gitignore`、Composeファイル、README、開発設定、テストなど、本番へ不要なファイルの標準除外を拡充
- ルート相対の除外パターンに対応し、プラグインやテーマ内のREADMEは維持
- プロジェクト作成画面の日本語説明が切れないようスクロール、横幅、説明配置を調整

## 検証

- macOS Apple Silicon版の起動スモークテストとZIP整合性を確認
