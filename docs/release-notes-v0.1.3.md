# v0.1.3

## 追加

- メニューバーに「設定」と「ヘルプ」→「バージョン情報」を追加
- SSH接続項目ごとの起動時マスク設定と、画面内の一時マスク解除を追加
- 無条件上書きの確認画面に「すべてチェック」「すべてチェック解除」を追加
- 接続先の確認コードをOS資格情報ストアへ保存
- 確認コードの保存状態表示と再登録操作を追加

## セキュリティ

- 旧SQLite内の確認コードを起動時にOS資格情報ストアへ移行
- 移行成功後はSQLiteの平文列を空にし、データベースを再構成
- 資格情報ストアを利用できない場合は同期操作を禁止
- 表示設定にはマスク有無だけを保存し、接続値そのものは保存しない

ストレージ媒体、OSバックアップ、同期サービスの過去バージョンに残ったデータまでの完全消去は保証しません。必要に応じて旧バックアップの保持方針も確認してください。

## 検証

- macOS上の固定依存環境で自動テスト82件に成功
- macOS Keychainバックエンドの検出を確認
