- 危険なリモートパスと重複マッピングの検証
- SSHホスト鍵フィンガープリントの厳格照合
- SFTP読み取り専用走査
- CLIの`scan`、`plan`、`dry-run`
- PySide6のローカル検査・読み取り専用ドライラン画面
- SQLiteプロジェクト保存層
- ローカルステージングとコピー後ハッシュ検証
- 複数プロジェクトの作成、編集、削除画面
- Laravelに対応する複数パスマッピング編集・切替
- ドライラン計画のSQLite保存と5分後の失効
- 新しい計画による同一マッピングの旧計画失効
- ADD・UPDATE対象だけを固定するジョブ別ステージング

- GUIの「計画を再検証」操作
- XServerテスト用ディレクトリへの読み取り専用実接続試験
- SSH認証、ホスト鍵照合、空ディレクトリ走査の成功確認

## 安全上、まだ無効にしている機能

- XServerへのアップロード
- リモートファイルの置換・削除
- リモートバックアップ
- 本番同期の承認
- 復元
- MySQL操作

## 推奨する次の実装単位

### 1. 読み取り専用の差分検出試験

- ローカルに無害なサンプルファイルを置いたADD検出
- ホスト鍵不一致時の停止確認
- WordPress `uploads/`、Laravel `storage/`が読み込まれないことの確認
- 数千〜数万ファイルでの性能計測

### 2. バックアップ機能

- 上書き対象だけをジョブ別領域へコピー
- コピー後SHA-256検証
- マニフェストと操作ジャーナル保存
- バックアップ失敗時に公開ファイルを変更しないテスト

### 3. 復元機能

- バックアップマニフェストからのファイル単位復元
- 公開側が外部変更済みの場合の上書き禁止
- 復元前後のSHA-256検証
- 未完了ジョブの起動時検出

### 4. 承認付きアップロード

- 一時ファイルへの転送
- 転送後SHA-256検証
- 同一ディレクトリ内リネーム
- 計画再検証と一回限りの承認
- 通信切断と異常終了の回復テスト

バックアップと復元が完成するまで、本番同期ボタンは追加しない。
