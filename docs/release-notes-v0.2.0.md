# v0.2.0

## 停止と再開

- 承認付き同期、無条件上書き、WordPressセットアップに「処理を停止」を追加
- 一時ファイルを残さない、またはロールバックできる安全な区切りで停止
- アプリ終了時は実行中の処理を安全に停止してから終了
- 停止、エラー、予期しないアプリ終了を操作履歴に保存し、選択中のプロジェクトから再開可能

## アプリアイコン

- ローカルからサーバーへの安全な同期と停止・再開を表す専用アイコンを追加
- macOSのICNSとWindowsのICOを各バイナリに組み込み

## 承認付き同期

- 再開用の差分計画とステージングを保持
- 期限切れ後でも、ローカル、XServer、設定、ステージングのハッシュがすべて一致した場合だけ再開
- 再開前に最終承認を再度表示

## WordPressセットアップ

- DB準備、SQLインポート、ファイルと`wp-config.php`の配置、URL置換のチェックポイントを保存
- 既存DBのテーブルとXServer上のWordPressを検査し、完了済みのSQLインポートやファイル転送をスキップ
- ファイル転送中のエラーで一部配置になった場合は、SQLを再投入せずファイル配置から再開
- v0.1.9の失敗履歴にチェックポイントがない場合も「中断したセットアップを再開…」からリモート状態を検査して再開
- DBパスワード、XServer APIキー、SSH鍵パスフレーズは保存せず、再開時に再入力

## 無条件上書き

- ファイル境界で停止し、完了済みファイルを操作履歴に保存
- 再開時は未完了ファイルを再選択・再承認

## 検証

- 自動テストに成功
- macOS Apple Silicon版とWindows x64版のビルド、起動、アーカイブ整合性を確認
- Windowsインストーラーのインストール、起動、アンインストールを確認
